# Spotify Music Data Analysis 🎵

## 1. Introduction
This project analyzes Spotify music data to understand song popularity, music genres, and audio features using Python and Data Science techniques.

## 2. Problem Statement
The main aim is to identify the characteristics of popular songs, compare different music genres, and group similar songs using machine learning.

## 3. Objectives
- Analyze Spotify music data.
- Study the relationship between audio features and popularity.
- Compare different music genres.
- Identify characteristics of popular songs.
- Apply K-Means clustering to group similar songs.
- Visualize results using graphs.

## 4. Dataset
**Dataset:** Spotify Tracks Dataset

**Source:** Kaggle

**Link:** https://www.kaggle.com/datasets/maharshipandya/-spotify-tracks-dataset

The dataset contains song names, artists, genres, popularity scores, and audio features.

### Important Attributes
- Track Name: Name of the song.
- Artists: Name of the artist.
- Popularity: Popularity score.
- Danceability: How suitable a song is for dancing.
- Energy: Intensity of the song.
- Valence: Musical positivity.
- Acousticness: Acoustic characteristics.
- Tempo: Speed of the music.
- Loudness: Overall loudness.

## 8. Machine Learning Algorithm
**K-Means Clustering**

K-Means is an unsupervised machine learning algorithm used to group similar songs based on audio features such as energy, danceability, valence, and tempo.

Four clusters are used in this project.
